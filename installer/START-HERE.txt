GLAZE USB INSTALLER FOR CASIO BE-300

Everything needed is included. No CF card, system Python, separate firmware
or additional download is needed.

macOS: drag Glaze Installer into Applications and open it.
Windows: run setup and launch Glaze Installer. If needed, use USB driver setup
in the app. In Zadig, enable Options -> List All Devices. Select USB ID 07CF:2002
(BE-300 or Unknown Device #1, Casio) and install libusbK. Replace an existing
WinUSB binding too: it cannot perform the device reset needed after RAM restarts.
Keep only one BE-300 connected.

On the BE-300, open Connections -> PC Connect -> Connection method and select
'USB' (not serial). Then connect USB and external power, choose your apps, and
click Install Glaze.
If NAND space is insufficient, use Windows CE to delete built-in apps you no
longer need, keeping PC Connect available, then retry installation.
Hello is not included; Windows CE compatibility starts unchecked. WL54-CF
Wi-Fi firmware is an optional hardware choice.
Detection, preparation, flashing and restart happen automatically.
During GlazeBoot, the BE-300 shows a temporary installation screen and stays
awake. Glaze is fully installed only after the final NAND boot completes. Keep USB
and power connected until the app finishes. Details are available if needed.

Save Windows CE backup and Verify Windows CE are optional. They start enabled.
Uncheck backup to keep no CE restore copy. Uncheck verification to skip the
extra CE read and execution probe. A temporary device read is still needed
for image placement and flash consistency. Glaze image and write checks stay on.

Backups are saved automatically to Documents/Glaze Backups unless changed.
After installation, Open backup shows the saved folder. Keep that entire folder
for Restore Windows CE. CE RAM files are cleared when Glaze starts, so save
anything important from CE's volatile object store beforehand.

These are development builds. See installer/VALIDATION.md in the source checkout
for the recorded Windows and hardware validation results.

ALREADY RUNNING GLAZE?
Wake/unlock Glaze, connect USB and power, then open Manage apps & hardware.
Additional apps: select targets, then Install apps or Uninstall selected apps.
Uninstall removes the selected app's saved data after confirmation. Unchecked
additional apps stay installed; installing updates preserves their saved data.
Built-in apps and Optional hardware: check what to keep, then Apply built-ins &
hardware. Files, Settings and system services are protected. WL54-CF support
includes the offline Marvell firmware pair and its license notice. Applying
these choices requires a matching OS build and external power, saves a checked
Glaze backup, retains files/settings/app data, and restarts the BE-300.
Update Glaze OS installs the standard signed OS bundled here, including its
standard built-in apps and firmware choices. Apps and saved data are preserved.
Keep power connected during the minutes-long OS installation. If boot verification
is incomplete, reconnect and choose Check status before retrying.
